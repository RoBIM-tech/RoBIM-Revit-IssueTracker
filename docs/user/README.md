# BIM 이슈 검토 (Issue Tracker) 사용자 설명서

Revit 내부에서 도면/모델을 검토하면서 ACC(Autodesk Construction Cloud)와 유사한 양식으로 이슈를 기록하고 관리할 수 있는 독립 Add-in 도구입니다.

---

## 주요 기능 및 사용 방법

### 1. 모델리스(Modeless) 동작
- 창을 띄워둔 상태에서도 Revit 작업 화면(도면, 3D 뷰 등)을 자유롭게 조작하고 모델을 탐색할 수 있습니다.
- 작업 표시줄이나 리본 메뉴에서 다시 클릭하더라도 창이 중복 실행되지 않고 기존 창으로 포커스가 이동합니다.

### 2. 중앙 파일 기준 `./issue` 자동 폴더 관리
- 중앙 모델이 있는 디렉토리를 감지하여 그 하위에 `./issue` 폴더를 자동 생성합니다.
- 각 이슈는 `ISSUE-0001.json` 형태의 파일과 스냅샷 이미지로 저장되므로 별도의 DB 서버 없이도 팀원 간 공유 및 백업이 용이합니다.
- 상단의 **[폴더 열기]** 버튼을 통해 이슈 파일들이 저장된 폴더를 탐색기에서 바로 확인할 수 있습니다.

### 3. ACC 스타일 표준 이슈 및 분류 체계 (공종1, 공종2, 우선순위, 유형, 원인)
- **공종 1 & 공종 2**: 기본 필드로 제공되며, 프로젝트별 대분류(건축, 구조, 설비 등)와 세부공종(골조, 마감, 배관 등)을 관리합니다.
- **우선순위(Priority)**: 긴급, 높음, 보통, 낮음
- **유형(Type)**: 설계검토, 품질, 간섭(Clash), 안전, 시공성, 법규/인허가, 기타
- **근본 원인(Root Cause)**: 설계 누락, 모델링 오류, 공종 간섭, 기준 미달, 발주처 요청, 현장 여건, 기타
- **상태(Status)**: Open, In Review, Pending, Closed, Void
- 상단의 **[분류/필드 설정]** 버튼을 통해 프로젝트에 맞게 공종1/2, 유형, 근본원인, 우선순위 선택지를 자유롭게 추가/수정/삭제할 수 있습니다.

### 4. 연계 뷰 (Active View) 및 자동 이동
- 이슈 작성 시 현재 작업 중인 Revit 활성 뷰가 자동으로 연결됩니다. (필요 시 **[현재 뷰 연계]** 버튼으로 변경 가능)
- 이슈를 검토할 때 **[뷰 열기/이동]** 버튼을 누르면 해당 이슈가 작성된 도면/3D 뷰로 화면이 즉시 전환되고 연계된 객체들이 하이라이트/확대됩니다.

### 5. 객체 단일/다중/영역 일괄 선택
- **영역 드래그 선택 (박스)**: 마우스 드래그 한 번으로 사각형 영역 내의 모든 객체를 일괄 선택하여 연결.
- **현재 선택 객체**: Revit 화면에서 이미 다중 선택해 둔 객체들을 원클릭으로 바인딩.
- **다중 클릭 선택**: Ctrl 키를 누른 채 객체들을 하나씩 클릭하여 선택.
- **객체로 이동/줌**: 연계된 객체들을 Revit 모델에서 자동으로 하이라이트 및 확대 표시.

### 6. 참여자(사용자) 관리 및 Revit Username 연계
- 상단의 **[참여자 관리]** 버튼을 통해 프로젝트 참여자(실명, Revit Username, 소속 회사)를 등록할 수 있습니다.
- **작성자 자동 입력**: 현재 Revit 로그인 사용자명(`doc.Application.Username`)을 기반으로 작성자가 자동으로 입력됩니다.
- **담당자 선택**: 등록된 사용자 목록에서 손쉽게 담당자를 선택할 수 있으며, 직접 입력도 가능합니다.

### 7. 사용자별 목록 열(Columns) 개별 설정
- 상단의 **[열 설정]** 버튼을 통해 이슈 테이블에 표시할 열(번호, 상태, 우선순위, 공종1, 공종2, 제목, 담당자, 작성자, 연계뷰, 마감일 등)을 사용자 취향대로 켜고 끌 수 있습니다.
- 이 설정은 중앙 파일이 아닌 **각 사용자의 PC 로컬 환경에 개별 저장**되므로 다른 팀원의 화면에 영향을 주지 않습니다.
