# BIM 이슈 검토 (Issue Tracker) 사용자 설명서

Revit 내부에서 도면/모델을 검토하면서 ACC(Autodesk Construction Cloud)와 유사한 양식으로 이슈를 기록하고 관리할 수 있는 독립 Add-in 도구입니다.

---

## 주요 기능 및 사용 방법

### 1. 간섭 대비 공종 1 & 공종 2 선택 (공통 공종 목록)
- 공종 1과 공종 2는 대분류/소분류가 아니라 **각 공종 간 간섭(Clash) 검토를 대비한 구성**입니다.
- 두 필드 모두 프로젝트의 단일 공종 목록(건축, 구조, 기계, 전기, 소방, 토목 등)을 공유하며, 간섭이 없는 단일 이슈일 경우 공종 2를 `(해당 없음)`으로 지정할 수 있습니다.
- 목록 테이블에는 `건축 ⚡ 기계` 형태로 한눈에 알아보기 쉽게 표시됩니다.

### 2. 작성자 및 담당자 `이름 (회사)` 형식 & 신규 등록 유도
- 모든 작성자 및 담당자는 **`홍길동 (A건축)`** 형식으로 명확하게 관리됩니다.
- **Revit 사용자 자동 인식**: 현재 로그인된 Revit Username이 프로젝트 참여자 목록에 없으면 자동으로 등록 팝업을 띄워 실명과 소속 회사를 등록하도록 안내합니다.
- **담당자 신규 등록**: 담당자에 등록되지 않은 이름을 입력하고 저장할 경우, 자동으로 신규 참여자로 추가할지 확인창을 제공합니다.

### 3. 댓글 및 자동 수정 이력 (Activity History)
- 이슈 상세 화면 하단에 **댓글(Comments) 및 수정 내역 타임라인**이 제공됩니다.
- 이슈 검토자가 댓글을 직접 작성하여 협의할 수 있습니다.
- **자동 수정 이력 기록**: 이슈 수정 시 변경된 항목(예: 상태가 `Open` → `In Review`로 변경, 담당자 변경 등)을 시스템이 감지하여 자동으로 `[수정 내역]` 시스템 댓글을 타임라인에 기록합니다.

### 4. 삭제 대신 안전한 아카이브(보관함) 이동 & 복원
- `[보관함 이동(삭제)]` 클릭 시 영구 삭제되지 않고 `./issue/archive/` 폴더로 이슈 JSON과 모든 스냅샷이 안전하게 격리 이동됩니다.
- 상단 필터바의 **[보관함(아카이브)]** 체크박스를 켜면 보관된 이슈 목록을 열람할 수 있으며, 언제든지 **[보관함에서 복원]** 버튼으로 다시 활성화할 수 있습니다.

### 5. 다중 스냅샷 갤러리 & 클릭 확대 뷰어
- 한 이슈에 여러 장의 스냅샷 이미지를 캡처하거나, 외부 이미지 파일(JPG/PNG)을 추가할 수 있습니다.
- 썸네일을 클릭하면 **전용 이미지 뷰어(`ImageViewerDialog`)**가 열려 마우스 휠 줌(확대/축소) 및 원본 크기 확인이 가능합니다.

### 6. 상단 제목(열 헤더) 커스텀 및 클릭 시 정렬 (Sorting)
- 상단의 **[상단 제목/열 설정]** 버튼을 통해 각 열의 표시 여부뿐만 아니라 **상단 제목(헤더 텍스트)**을 사용자가 원하는 명칭으로 직접 수정할 수 있습니다.
- **원클릭 정렬**: 테이블 상단의 열 헤더를 클릭하면 해당 필드(번호, 상태, 우선순위, 공종, 제목, 담당자, 마감일 등)를 기준으로 **오름차순/내림차순 정렬**됩니다.
- 상세 폼 상단 헤더에도 상태, 우선순위, 공종 뱃지와 작성자 정보가 직관적으로 요약 표시됩니다.
