# BIM 이슈 검토 (Issue Tracker) 사용자 설명서

Revit 내부에서 도면/모델을 검토하면서 ACC(Autodesk Construction Cloud)와 유사한 양식으로 이슈를 기록하고 관리할 수 있는 독립 Add-in 도구입니다.

---

## 주요 기능 및 사용 방법

### 1. 모델리스(Modeless) 동작
- 창을 띄워둔 상태에서도 Revit 작업 화면(도면, 3D 뷰 등)을 자유롭게 조작하고 모델을 탐색할 수 있습니다.
- 작업 표시줄이나 리본 메뉴에서 다시 클릭하더라도 창이 중복 실행되지 않고 기존 창으로 포커스가 이동합니다.

### 2. 중앙 파일 기준 `./issue` 자동 폴더 관리
- 중앙 모델이 있는 디렉토리를 감지하여 그 하위에 `./issue` 폴더를 자동 생성합니다.
- (로컬 파일인 경우 해당 파일 경로 기준, 저장되지 않은 모델인 경우 내 문서 내 `RoBIM_Issues` 폴더를 사용합니다.)
- 각 이슈는 `ISSUE-0001.json` 형태의 파일과 스냅샷 이미지로 저장되므로 별도의 DB 서버 없이도 팀원 간 공유 및 백업이 용이합니다.
- 상단의 **[폴더 열기]** 버튼을 통해 이슈 파일들이 저장된 폴더를 탐색기에서 바로 확인할 수 있습니다.

### 3. ACC 스타일 표준 이슈 작성
- **상태(Status)**: Open, In Review, Pending, Closed, Void
- **유형(Type)**: 설계검토, 품질, 간섭(Clash), 안전, 시공성, 기타
- **근본 원인(Root Cause)**: 설계 누락, 모델링 오류, 공종 간섭, 기준 미달, 발주처 요청, 기타
- **기본 속성**: 제목, 담당자, 마감일, 위치/층, 상세 설명

### 4. 객체 연계 및 화면 캡처
- **뷰에서 선택**: 버튼 클릭 후 Revit 뷰에서 연계할 객체를 마우스로 직접 클릭/드래그하여 선택 (ElementId 및 UniqueId 연계).
- **현재 선택 객체**: Revit에서 이미 선택되어 있는 객체를 한 번의 클릭으로 이슈에 바인딩.
- **객체로 이동/줌**: 목록에서 이슈를 확인하면서 [객체로 이동/줌]을 클릭하면 Revit 모델에서 해당 객체를 자동으로 하이라이트 및 확대 표시.
- **현재 화면 캡처**: 활성화된 Revit 뷰포트를 고해상도 이미지(PNG)로 캡처하여 이슈에 썸네일로 즉시 첨부.

### 5. 사용자 정의 필드 (Custom Fields)
- 상단의 **[커스텀 필드 설정]** 버튼을 통해 프로젝트별로 필요한 필드를 자유롭게 추가/삭제할 수 있습니다.
- 지원 유형:
  - **Text**: 텍스트 입력창 (예: 도면 번호, 상세 위치)
  - **Dropdown**: 콤보박스 선택 (예: 공종 - 건축, 구조, 설비 등)
  - **Radio**: 라디오버튼 단일 선택 (예: 긴급도 - 긴급, 보통, 낮음)
  - **Checkbox**: 예/아니오 체크박스 (예: 감리 확인 여부)
- 생성된 필드는 이슈 작성 및 수정 화면에 동적으로 반영되어 바로 사용할 수 있습니다.
